# "Jack of All Trades, Master of None"

My name is **Jeremiah Kylle Chu Baun**. I love exploring all the different engineering and technical domains that exist, with a special interest in how physical world data can be utilized and applied in different ways.

---

### 💻 My Technical Stack

> *My philosophy is that computers all speak the same language; the only challenge is the translation. Once you figure out the fundamentals, it gets pretty easy to tinker around different languages and use them in different ways.*

* **Python:** My first language and what made me fall in love with elegant code and abstracted systems. The most versatile language and the ultimate multi-tool of tech.
* **C++:** Applied within my ESP32 hardware projects—the only real roadblock has been the lack of physical hardware to play with!
* **HTML / React:** Frontend was always my worst enemy, especially since I'm not the most aesthetic-driven, but it's always made things work when needed.

---

### 🛠️ My Toolbox

* **OS:** Arch Linux — *Sorry Microslop, but too much bloatware made my potato laptop burn up, so flip you. Plus, Arch has made working with multiple windows on one screen an absolute dream.*
* **IDE:** VS Code — *Okay, might sound a bit like a hypocrite, but I haven't explored any others yet, and the sheer amount of extensions makes tinkering around super fun.*
